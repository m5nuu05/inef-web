Bachillerato Técnico Vocacional en Desarrollo de Software

Aprende a crear aplicaciones web, bases de datos y soluciones tecnológicas.

¿En qué consiste la especialidad?

Esta especialidad capacita a los estudiantes en programación, maquetación web (HTML, CSS, JavaScript), bases de datos y desarrollo de lógica de software para prepararles hacia el ámbito tecnológico laboral y universitario.

Perfil del Egresado

Al finalizar los 3 años de estudio, el estudiante será capaz de diseñar sitios web responsivos, gestionar sistemas informáticos y aplicar metodologías de desarrollo de software.
